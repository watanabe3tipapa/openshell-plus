1. アーキテクチャ概要 #

OpenShell は Gateway（コントロールプレーン）と Sandbox（データプレーン）の 2 層構造で構成されています。 UI/UX を追加する場合、以下の 2 つのユースケースを同時に満たす必要があります。

💻
ローカル UI
開発者のマシン上で直接動作するデスクトップ / CLI / ブラウザ UI
→
🌐
外部 Web UI
Gateway 経由で公開された HTTPS エンドポイントとして動作する Web UI

両方を 1 つのコードベースで実現するための推奨アーキテクチャは、「FastAPI + 軽量フロントエンド」です。 FastAPI は ASGI サーバとして動作し、ローカルでは uvicorn で直接起動、 外部公開時は OpenShell の service expose で Gateway 経由の HTTPS URL を取得します。

ℹ なぜ FastAPI か
OpenShell の Python SDK は同期的・非同期の両方の API を提供しており、FastAPI の非同期ハンドラと相性が良いです。また、Gradio をマウントすれば AI チャット UI も同じエンドポイントに統合できます。

3. OpenShell SDK 連携 #

OpenShell の Python SDK は SandboxClient を中心に、サンドボックスの作成・実行・監視をプログラムから制御できます。 UI/UX レイヤーから呼び出すためのラッパーを作成します。

3.1 クライアントラッパーの実装

python# src/openshell_ui/core/client.py
from contextlib import asynccontextmanager
from typing import AsyncGenerator
import openshell
from openshell import SandboxClient, SandboxSession

class OpenShellManager:
    """OpenShell SDK の非同期ラッパー"""

    def __init__(self, gateway_url: str | None = None):
        self.gateway_url = gateway_url
        self._client: SandboxClient | None = None

    async def connect(self) -> None:
        """Gateway への接続を確立"""
        if self.gateway_url:
            self._client = SandboxClient(target=self.gateway_url)
        else:
            # ローカルの active cluster を自動検出
            self._client = SandboxClient.from_active_cluster()

    async def list_sandboxes(self):
        """サンドボックス一覧を取得"""
        if not self._client:
            raise RuntimeError("Not connected")
        return self._client.list()

    async def create_sandbox(
        self,
        name: str,
        image: str = "base",
        cpu: str = "1",
        memory: str = "2Gi",
        gpu: bool = False,
        labels: dict | None = None,
    ):
        """サンドボックスを作成"""
        if not self._client:
            raise RuntimeError("Not connected")
        spec = {
            "name": name,
            "image": image,
            "cpu": cpu,
            "memory": memory,
            "gpu": gpu,
            "labels": labels or {},
        }
        return self._client.create(spec=spec)

    async def exec_command(self, sandbox_id: str, command: list[str]) -> str:
        """サンドボックス内でコマンドを実行"""
        session = SandboxSession(self._client, sandbox_id)
        result = session.exec(command)
        return result.stdout

    async def delete_sandbox(self, sandbox_id: str) -> None:
        """サンドボックスを削除"""
        self._client.delete(sandbox_id)

    async def disconnect(self) -> None:
        if self._client:
            self._client.close()
            self._client = None


@asynccontextmanager
async def get_manager() -> AsyncGenerator[OpenShellManager, None]:
    manager = OpenShellManager()
    await manager.connect()
    try:
        yield manager
    finally:
        await manager.disconnect()

4. ローカル UI の実装 #

ローカル環境では、開発者が uv run で即座に UI を起動できることが重要です。 2 つの選択肢を提供します：軽量な REST API ベースの Web UI と、Gradio による AI チャット UI です。

4.1 FastAPI メインアプリケーション

python# src/openshell_ui/api/main.py
from fastapi import FastAPI, Depends, HTTPException
from fastapi.staticfiles import StaticFiles
from fastapi.middleware.cors import CORSMiddleware
from contextlib import asynccontextmanager

from openshell_ui.core.config import get_settings, Settings
from openshell_ui.core.client import OpenShellManager
from openshell_ui.api import sandbox, chat
import gradio as gr
from openshell_ui.gradio_app.main import create_gradio_app

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    app.state.manager = OpenShellManager()
    await app.state.manager.connect()
    yield
    # Shutdown
    await app.state.manager.disconnect()

app = FastAPI(
    title="OpenShell UI",
    description="Local & Web Hybrid UI for NVIDIA OpenShell",
    version="0.1.0",
    lifespan=lifespan,
)

# CORS
settings = get_settings()
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# API ルータ
app.include_router(sandbox.router, prefix="/api/sandboxes", tags=["sandboxes"])
app.include_router(chat.router, prefix="/api/chat", tags=["chat"])

# Gradio マウント
if settings.enable_gradio:
    gradio_app = create_gradio_app()
    app = gr.mount_gradio_app(app, gradio_app, path="/gradio")

# 静的ファイル
app.mount("/", StaticFiles(directory="src/openshell_ui/ui", html=True), name="static")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("openshell_ui.api.main:app", host=settings.host, port=settings.port, reload=settings.debug)

4.2 サンドボックス管理 API

python# src/openshell_ui/api/sandbox.py
from fastapi import APIRouter, Request, HTTPException
from pydantic import BaseModel
from typing import Optional

router = APIRouter()

class SandboxCreate(BaseModel):
    name: str
    image: str = "base"
    cpu: str = "1"
    memory: str = "2Gi"
    gpu: bool = False

class SandboxResponse(BaseModel):
    id: str
    name: str
    status: str
    labels: dict

@router.get("/", response_model=list[SandboxResponse])
async def list_sandboxes(request: Request):
    manager = request.app.state.manager
    boxes = await manager.list_sandboxes()
    return [
        SandboxResponse(
            id=b.id,
            name=b.name,
            status=b.status,
            labels=b.labels or {},
        )
        for b in boxes
    ]

@router.post("/", response_model=SandboxResponse)
async def create_sandbox(payload: SandboxCreate, request: Request):
    manager = request.app.state.manager
    sb = await manager.create_sandbox(
        name=payload.name,
        image=payload.image,
        cpu=payload.cpu,
        memory=payload.memory,
        gpu=payload.gpu,
    )
    return SandboxResponse(
        id=sb.id,
        name=sb.name,
        status=sb.status,
        labels=sb.labels or {},
    )

@router.delete("/{sandbox_id}")
async def delete_sandbox(sandbox_id: str, request: Request):
    manager = request.app.state.manager
    await manager.delete_sandbox(sandbox_id)
    return {"deleted": sandbox_id}

import gradio as gr
from openshell_ui.core.client import get_manager

async def chat_with_sandbox(message: str, history: list):
    """サンドボックス内のエージェントと対話"""
    async with get_manager() as manager:
        # 例: 既存のサンドボックスにコマンド送信
        # 実際にはエージェント固有のプロトコルに応じて実装

            command=["echo", f"Received: {message}"],
        )
        return result

def create_gradio_app() -> gr.Blocks:
    with gr.Blocks(title="OpenShell Chat", theme=gr.themes.Soft()) as demo:
        gr.Markdown("# OpenShell Agent Chat")

        clear = gr.Button("クリア")

        msg.submit(chat_with_sandbox, [msg, chatbot], [chatbot])
        clear.click(lambda: None, None, chatbot, queue=False)

    return demo

const API_BASE = "/api";

async function loadSandboxes() {
    const res = await fetch(`${API_BASE}/sandboxes/`);
    const data = await res.json();
    const tbody = document.querySelector("#sandbox-table tbody");
    tbody.innerHTML = data.map(sb => `
        <tr>
            <td>${sb.id}</td>
            <td>${sb.name}</td>
            <td><span class="status"></span> ${sb.status}</td>
            <td><button class="btn" onclick="deleteSandbox('${sb.id}')">削除</button></td>
        </tr>
    `).join("");
}

async function createSandbox() {
    const name = document.getElementById("name").value;
    await fetch(`${API_BASE}/sandboxes/`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ name }),
    });
    loadSandboxes();
}

async function deleteSandbox(id) {
    await fetch(`${API_BASE}/sandboxes/${id}`, { method: "DELETE" });
    loadSandboxes();
}

6. サービス公開戦略 #

OpenShell の service expose コマンドは、サンドボックス内で動作するサービスを Gateway 経由で公開する最も重要な機能です。 ローカル Gateway とリモート Gateway で挙動が異なります。

Gateway 種別公開 URL認証用途
ローカル (loopback)http://*.openshell.localhost不要開発・デバッグ
リモート (HTTPS)https://*.openshell.example.comGateway 認証必須本番・共有

6.1 公開手順

bash# 1. サンドボックス作成（UI サーバを含むカスタムイメージ）
openshell sandbox create --from ./my-ui-image --name ui-sandbox

# 2. サンドボックス内で UI サーバ起動（localhost:8080 で待受）
openshell sandbox connect ui-sandbox
sandbox$ uv run python -m openshell_ui.api.main

# 3. 別ターミナルからポート公開
openshell service expose ui-sandbox 8080 web-ui

# 4. 出力された URL を確認
openshell service get ui-sandbox web-ui

6.2 自動公開スクリプト

bash#!/usr/bin/env bash
# scripts/deploy-ui.sh
set -euo pipefail

SANDBOX_NAME="${1:-openshell-ui}"
PORT="${2:-8080}"
SERVICE_NAME="${3:-web}"

# サンドボックスが存在しなければ作成
if ! openshell sandbox list | grep -q "$SANDBOX_NAME"; then
    echo "Creating sandbox: $SANDBOX_NAME"
    openshell sandbox create --name "$SANDBOX_NAME" --from base
fi

# サービスを公開
echo "Exposing port $PORT as service '$SERVICE_NAME'..."
URL=$(openshell service expose "$SANDBOX_NAME" "$PORT" "$SERVICE_NAME" --format json | jq -r '.url')
echo "UI available at: $URL"
⚠ 注意
リモート Gateway で公開する場合、Gateway の認証（OIDC / mTLS）が必要です。OpenShell SDK は Bearer Token 自動更新に対応しているため、長時間稼働する UI でも認証が切れることはありません。

7. セキュリティとポリシー #

UI を公開する場合、特に外部 Web 環境ではセキュリティポリシーの設定が不可欠です。 OpenShell のポリシーは YAML で宣言的に記述し、ネットワーク・推論ルーティングはホットリロード可能です。

7.1 UI 用ポリシー例

yaml# policy/ui-policy.yaml
apiVersion: openshell.nvidia.com/v1
kind: Policy
metadata:
  name: ui-sandbox-policy

  network:
    egress:
      # UI サーバが必要とする外部 API のみ許可

      # 推論ルーティング

  inference:
    local:

      model: codellama:7b
  filesystem:
    allow:
      - /workspace/**
      - /tmp/**
    deny:
      - /etc/shadow
      - ~/.ssh/*
  process:
    allow:
      - python
      - uv
      - node
    deny:
      - sudo
      - su

7.3 CORS と認証の分離

FastAPI 側の CORS は「どのオリジンからのリクエストを受け入れるか」を制御し、 OpenShell のポリシーは「サンドボックスがどの外部ホストに接続できるか」を制御します。 両者は独立して機能するため、以下のように設計します。

  • FastAPI CORS: フロントエンドのホスト（ローカルなら localhost、Web なら公開ドメイン）のみ許可
  • OpenShell Network Policy: バックエンド API（OpenAI, GitHub 等）のみ許可

8. ハイブリッド実行モード #

ローカルと Web の両方で同じコードを動かすため、実行時にモードを切り替える仕組みが必要です。 環境変数と Gateway の検出で自動判定します。

8.1 モード検出ロジック

python# src/openshell_ui/core/mode.py
import os
from enum import Enum

class RunMode(Enum):
    LOCAL = "local"       # 開発者マシンで直接実行
    SANDBOX = "sandbox"   # OpenShell サンドボックス内で実行
    WEB = "web"           # Gateway 経由で外部公開

def detect_mode() -> RunMode:
    """実行環境を自動検出"""
    # OpenShell サンドボックス内では OPENSHELL_SANDBOX_ID が設定される
    if os.environ.get("OPENSHELL_SANDBOX_ID"):
        return RunMode.SANDBOX
    # 明示的に WEB モードが指定されている場合
    if os.environ.get("OSUI_MODE") == "web":
        return RunMode.WEB
    return RunMode.LOCAL

def get_gateway_url(mode: RunMode) -> str | None:
    """モードに応じた Gateway URL を返す"""
    if mode == RunMode.SANDBOX:
        # サンドボックス内からは通常 localhost:18080
        return os.environ.get("OPENSHELL_GATEWAY", "http://localhost:18080")
    if mode == RunMode.WEB:
        return os.environ.get("OSUI_GATEWAY_URL")
    # LOCAL: active cluster を自動検出
    return None
